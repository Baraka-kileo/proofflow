# User flows

## SME

Create application → upload purchase order, delivery evidence and invoice → enter all evidence values → submit declaration → run deterministic checks → request customer verification → submit funding-ready package → review and respond to a funding proposal.

## Large customer

Open assigned requests → inspect source evidence and checks → use authorised customer records where available → resolve exceptions → confirm or dispute through an authenticated declaration.

## Funder

Open eligible funding-ready package → inspect evidence, verification and customer confirmation → perform KYC/KYB and underwriting externally → record compliance progress → independently decline or create a funding proposal → complete contracting and disbursement in the regulated funding system.

Evidence verified and funding approved are separate states.
